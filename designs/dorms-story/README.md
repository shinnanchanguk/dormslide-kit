# 디자인 ① 도름스 탄생비화 (크로마)

따뜻한 종이 바탕, 필름 그레인, 기하 산세리프 제목(Space Grotesk · Wanted Sans), 모노 라벨(JetBrains Mono).
그래프·연표·인용 카드가 장을 넘길 때마다 차례로 떠오르는 이야기형 디자인이다. 도름슬라이드 본체의 「도름스는 어떻게 탄생했고, 어떻게 성장하고 있을까요?」 덱(2026. 9. 30.)에서 옮겼다.

- 포인트 색(표식 색): `#1e5fce`
- 샘플: `samples/dorms-story/deck.json` (63장) · 화면 `/?sample=dorms-story`
- 배치마다 실제로 어떤 칸을 읽는지는 샘플의 그 쪽 `payload` 를 보면 가장 빠르다(`tables` 의 열 순서가 곧 약속이다).

배치 없이(`layout` 을 비우고) 쓰면 제목 + 글 블록만 있는 기본 장이 된다. 글 블록은 `p`(본문) · `lead`(큰 문장) · `note`(작은 설명) · `rule`(가로줄)이고, 글 안의 강조는 `{ "t": "hl", "v": "강조할 말" }` 이다.
