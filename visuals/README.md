# 시각화 조각

한 장에서 쓰는 시각화 표현이다. 각 폴더의 `demo.json` 이 작동 예시이고(`/?visual=<이름>`), `visual.json` 의 `layout` 을 장의 `payload.layout` 에 적으면 쓸 수 있다.
같은 배치 이름을 쓰는 디자인(지금은 탄생비화·시뮬레이션 계기판)이면 어느 디자인에서나 그 디자인의 모습으로 그려진다.

새 시각화 조각을 더할 때는 `CONTRIBUTING.md` 의 순서를 따른다. 새 배치가 필요하면 디자인 쪽 배치 코드(designs/dorms-story/layouts)에 더하고, 같은 배치를 다른 디자인 CSS 에도 입힌다.
