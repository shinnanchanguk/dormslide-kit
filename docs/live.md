# 실시간 기능 켜기 (발표자 따라오기 · 설문 모으기 · 링크 모으기)

학생 화면과 주고받는 기능은 데이터베이스가 있어야 돈다. 도름슬라이드는 **선생님 본인의 수파베이스(무료)** 를 쓴다.
학생 응답은 선생님 수파베이스에만 쌓이고, 도름스 서버로는 아무것도 가지 않는다.

> AI 에게: 아래를 차례로 대신 해 준다. 선생님이 직접 해야 하는 것은 수파베이스 가입·로그인과 대시보드 버튼 두세 번뿐이다.

1. **수파베이스 준비**: 계정이 없으면 도름스 플랫폼 연결하기 6~7장(https://dorms.school/vibe/followup)을 함께 따라간다.
   새 프로젝트를 만들 때 지역은 Northeast Asia (Seoul).
2. **익명 로그인 켜기**: 대시보드 → Authentication → Sign In / Providers → **Allow anonymous sign-ins** 켜기.
   학생은 이메일 없이 브라우저마다 익명 번호를 받는다. 그 번호로 한 사람 한 표를 지킨다.
3. **표 만들기**: 대시보드 → SQL Editor → `supabase/schema.sql` 전체를 붙여 넣고 Run.
   수파베이스 MCP 가 연결돼 있으면 AI 가 직접 실행해도 된다.
4. **열쇠 넣기**: Project Settings → API 에서 Project URL 과 anon(공개) 키를 복사해 `.env.local` 에 적는다(`.env.example` 참고).
   **service_role 키는 절대 쓰지 않는다.** `.env.local` 은 깃에 올라가지 않는다.
5. **덱에서 켜기**: `slides/content.json` 의 `meta.live` 를 `true` 로.
6. **수업할 때**: 배포한 주소를 열고 아래 띠의 **[발표 시작]** 을 누른다. 무작위 방 이름이 만들어지고 링크 공유 창이 뜬다. 학생은 그 QR 로 들어온다.
   선생님이 넘기면 학생 화면도 같은 장으로 넘어간다. 학생은 [발표자 따라가는 중] 을 눌러 혼자 넘겨 볼 수도 있다.
7. **기록 받기**: 발표자 화면 아래 **[모든 결과 내려받기]**를 누르면 모든 장의 설문·의견·링크를 CSV 한 파일로 받는다. 엑셀에서 열어 쪽 번호와 질문별로 살펴볼 수 있다. 각 설문·게시판의 [결과 내려받기]는 해당 장만 받는다.
8. **수업이 끝나면**: 필요한 결과를 받은 뒤 [수업 끝내기]로 학생 응답을 지운다. 내려받은 파일은 선생님 컴퓨터에만 저장되며 도름스 서버에는 보내지 않는다.

실시간 모드가 꺼져 있으면 도구들은 '혼자 보는 판'으로 돈다(이 화면에서 누른 것만 센다). 수업 전에 모양을 확인할 때 쓰면 된다.
