# 도름슬라이드 DoRmSlide

**다 함께 만드는 오직 선생님들을 위한 슬라이드 프로젝트**

도름슬라이드는 선생님 대신 생각하고 슬라이드를 뚝딱 만들어 주지 않습니다. 선생님의 입력으로부터 출발해, 선생님의 생각을 예쁘고 효과적으로 전달될 수 있게 돕습니다. 이젠 슬라이드 디자인 및 시각화에 애쓰지 마시고, 슬라이드에 어떤 이야기를 담을지에만 집중하세요.

## 슬라이드 안에서 다 합니다

넘기기만 하면 수업과 발표에 필요한 것이 그 장 안에 생깁니다. 설문을 띄우려고 띵커벨을, 의견을 모으려고 패들렛을, 투표를 받으려고 멘티미터를 따로 열 필요가 없어요.

- 학생 화면이 선생님을 **따라 넘어가고**(발표자 따라오기)
- 그 장에서 바로 **객관식 설문·주관식 답·링크 모으기·의견 나누기**가 되고
- **유튜브·다른 수업 화면**이 슬라이드 안에서 열리고
- 도름이가 슬라이드 위를 **걸어 다닙니다**

## 이렇게 씁니다

가장 쉬운 길은 도름스 서재의 [도름슬라이드 책](https://dorms.school/collaboration?project=pub-ab69c9d3-3336-4eaf-b2e2-9132a855120a)에서 장마다 제목·내용을 적고(말로 해도 돼요) 디자인·도구를 끌어다 놓은 뒤, 만들어진 글을 내 AI(클로드 코드 · 코덱스 · 커서 등)에 붙여 넣는 것입니다.
AI 가 이 레포를 받아 슬라이드를 만들고, 개발 서버를 띄워 줍니다. 화면 아래 **[편집]** 을 누르면 글자를 그 자리에서 고칠 수 있어요.

직접 해 보려면:

```bash
git clone https://github.com/shinnanchanguk/dormslide-kit.git 내-슬라이드
cd 내-슬라이드 && npm install && npm run dev
```

- `http://localhost:5173/` 내 슬라이드 (`slides/content.json`)
- `http://localhost:5173/?sample=dorms-story` 샘플 「도름스 탄생비화」 63장
- `npm run build:html` HTML 파일 하나로 저장(인터넷 없이 열림)
